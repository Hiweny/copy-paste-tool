# 文本复制与文件保存工具

一个纯前端的文本工具：**上传文件一键复制内容**，或 **输入内容智能识别格式并下载为文件**。

🔗 在线访问：https://hiweny.github.io/copy-paste-tool/

## ✨ 功能

- **上传 → 复制**：点击或拖拽文本类文件，自动读取内容并一键复制到剪贴板
- **输入 → 下载**：粘贴 / 输入文本，智能检测语法推荐格式，也可手动选择，一键保存为文件
- **随机背景**：每次刷新自动更换二次元壁纸作为整页背景，按屏幕方向自动适配横图 / 竖图
- **智能识别**：内置 22 种语法检测器，自动判断 JSON / HTML / JS / Python / SQL / CSV / Markdown 等
- **23+ 格式**：txt · json · md · csv · xml · yaml · html · js · ts · css · py · java · go · rs · c · cpp · php · rb · sh · sql · log · ini · toml
- **纯本地**：文本处理都在浏览器完成，数据不上传服务器
- **深色模式**：自适应系统主题，也支持手动切换（跟随系统 / 浅色 / 深色）
- **移动端友好**：响应式布局，适配手机显示
- **防崩溃下载**：及时释放 `ObjectURL`、防抖处理、状态锁定，避免下载时页面卡死

## 🚀 本地预览

无需构建，直接用浏览器打开 `index.html` 即可；或启动一个静态服务器：

```bash
python3 -m http.server 8080
```

然后访问 http://localhost:8080
